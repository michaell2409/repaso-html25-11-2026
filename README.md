# 💀 HTML Review

HTML review exercises for my Web Applications exam (2nd year of the Microcomputer Systems and Networks vocational course, IES Lomo de la Herradura).

Open `index.html` to see the cover page with every exercise.

| File | Topic |
|---|---|
| ejercicio1.html | Basic page structure |
| ejercicio2.html | Text: headings, paragraphs, br, hr, sub and sup |
| ejercicio3.html | Lists: ol, ul and dl, nested lists |
| ejercicio4.html | Images: src, alt, width, title and paths |
| ejercicio5.html | Links: external, internal, target and images as links |
| ejercicio6.html | Tables: th, colspan, rowspan and cellpadding |
| ejercicio7.html | Layout: div with id, float, width and clear |
| simulacro.html | Final mock exam: everything together, from memory |

The exercises are written by hand, exactly as I solved them (mistakes included).
